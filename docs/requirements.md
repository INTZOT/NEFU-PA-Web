## 三、按主题展开

### 3.1 网站定位与目标

**双重定位（R-03）**，已由 [D-02](decisions.md) 落实为"展示区 / 服务区"分区准入：

| 区域 | 面向对象 | 典型诉求 | 访问频次 |
| --- | --- | --- | --- |
| 展示区 | 新生、校方与指导教师、校外爱好者、合作方 | 了解"我们是谁、做什么、怎么加入" | 低，一次性浏览 |
| 服务区 | 已在 QQ 群内的成员 | 看公告、报名活动、约球、录与查积分 | 高，重复访问 |

### 3.2 目标用户与使用场景

- 主要设备：手机；跨平台兼容 + 响应式（R-04）。
- 主要入口：QQ 群（R-05）；用户大概率处于 QQ 内置浏览器环境。
- 双端协同：QQ 群 + 机器人负责**签发邀请码并完成注册/绑定**，此后账号归网站，网站承担全部业务（[D-07](decisions.md)、[D-08](decisions.md)、[D-12](decisions.md)）。

**注册与登录流程（[D-12](decisions.md)）**：

```
私聊机器人
      │  发送"注册"
      ▼
机器人：首次 → 生成邀请码并与该 QQ 号永久绑定
        再次 → 返回同一条消息（同一个邀请码）
        已注册 → 拒绝
      ▼
机器人返回：邀请码 + 注册页面链接      ◀── 仅私聊，群聊中不得展示
      │  复制邀请码，打开网页
      ▼
注册页：姓名 / 学号 / 密码 / 邀请码  ──提交──▶ 注册完成
      │                                        （QQ 号由邀请码带入）
      ▼
日常登录：QQ号 + 密码  或  学号 + 密码
      │
      └─ 忘记密码 ──▶ 私聊"重置密码" ──▶ 机器人问新密码 ──▶ 发送 ──▶ 完成
                          （无校验 / 无频率限制 / 无二次确认）
```

**机器人职责最终范围（[D-14](decisions.md)）**：

| 做 | 不做 |
| --- | --- |
| 签发邀请码 | 通知推送 |
| 提供注册链接 | 报名、约球、查积分等业务操作 |
| 重置密码 | 在群聊中展示邀请码 |

### 3.5 运营、维护与权限

- 维护人力：**你一人**（R-12）。已直接塑造 [D-01](decisions.md)（免成员审批）、[D-04](decisions.md)（积分隔离）、[D-05](decisions.md)（免审核）、[D-06](decisions.md)（免学号核验）、[D-11](decisions.md)（免换绑审批）。
- 权限层次：**游客 / 成员**两层（管理员是成员的精化）；不存在"待审核"中间态。
- **账号运维已自助化**：换绑在个人主页完成（[D-11](decisions.md)），日常账号事务无需你介入。注销、找回等更深层事务尚未定义（Q20）。
- 更新内容：社团公告 + 活动发布。待落实（Q10）：能否只发一次。
- **整体自治度**：约球由成员自助、积分由双方互认、注册由机器人完成 —— 除公告与活动外，日常运行基本无需你介入。
